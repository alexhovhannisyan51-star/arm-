Matches are based on exact GRCh38 chromosome/position/ref/alt, with an rsID cross-check as a second pass. Multi-allelic sites are split per alt allele. Indel representation differences between callers can occasionally cause a real match to be missed.

Computational ACMG estimate

For variants in your file that aren't already classified in our ClinVar database, we can run a simplified ACMG-style check using live population frequency (gnomAD) and CADD deleteriousness data from myvariant.info. This only evaluates 5 of the ~28 official ACMG criteria (PM2, BA1, BS1, PP3, BP4) -- it has no access to functional studies, segregation data, de novo status, or hotspot information, so it will almost never reach a strict "Pathogenic" call, and that's intentional: those calls require stronger evidence than frequency and CADD alone can provide. This is not a clinical classification. Only simple single-nucleotide substitutions are checked (not indels), and only up to 500 unmatched variants per scan, out of respect for the third-party API.
